# SilentHelp

Uma aplicação web criada com a ideia de ajudar pessoas em situações de risco e também para responsáveis monitorarem seus 

## 📋 Funcionalidades

- [x] Cadastro de usuários
- [x] Login
- [x] Consulta de dados
- [X] Edição e exclusão de registros
- [X] Geolocalização GPS
- [X] Chat em tempo real
- [X] Responsividade
- [X] Verificação dos status do dispositivo (bateria, conexão, etc)
- [X] Emissão de alerta ao responsável conectado
- [X] Edição de perfil
- [X] Dashboard
- [X] 

## 🛠️ Tecnologias

- Node.js
- NestJS
- PostgreSQL
- Prisma ORM

## 📦 Instalação

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

Entre na pasta:

```bash
cd SEU-REPOSITORIO
```

Instale as dependências:

```bash
npm install
```

## ⚙️ Configuração

Crie um arquivo `.env` na raiz do projeto
e configure as variáveis necessárias.

Exemplo:

```env
DATABASE_URL="sua_url_do_banco"
PORT=3000
```

Não compartilhe senhas ou credenciais reais.

## ▶️ Como executar

```bash
npm run start:dev
```
